Source: the user-provided `Downloads/softsync_home_assets` package. The source
package was inspected before use; no UI screenshot is used as a page background.

88). Decorative WebP files remain at their original dimensions and were encoded
at the same quality. The 13 deliverable images total approximately 140 KiB.
